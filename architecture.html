Solar의 역할

Solar가 일하는 세 자리

Solar Pro 4는 서비스 안에서 요청을 해석하고, MCP 도구 안에서 판례를 대조하고, MCP를 개발할 때는 그 코드를 썼습니다.

01

서비스의 두뇌

GWS와 민원 분류에서 Solar Pro 4·Solar Decide가 요청을 해석하고 필요한 도구를 고릅니다. 온프렘에 설치하면 행정망 안에서 그대로 돕니다.

02

도구 안의 판단

근거 행성의 판례 대조·요약·번역·거주자 판정, 계산 행성의 PDF 표 추출. 키가 없으면 사용자가 쓰는 AI가 대신 판단합니다.

03

MCP를 만든 개발 도구

한글 서식·근거·계산 MCP는 Solar Pro 4로 코드를 쓰고 CodeSolar로 리뷰한 뒤 테스트로 검증했습니다. 결과물은 PyPI와 MCP Registry에 공개되어 있습니다.

요청 궤도

요청 하나가 지나가는 길

문서 작성

“이 메모를 ○○부 보고서로 만들어 줘”

  1. get_writing_guide로 그 기관의 작성 규칙 확인
  2. 메모를 □ → ㅇ → - 구조로 정리
  3. build_document가 기관 서식 HWPX 생성
  4. 경고가 있으면 고쳐서 다시 생성

근거 → 계산

“가지급금 인정이자, 근거와 금액은?”

  1. research_issue로 그해 조문·통칙·해석 조회
  2. compare_with_case로 판례 대조
  3. deemed_interest가 금액을 코드로 계산
  4. verify_citations로 인용 실재 확인

민원 처리

“이 민원, 어느 부서로?”

  1. Solar Decide(Jev)가 유형·담당 부서 판정
  2. 관련 법령 연결
  3. Solar Pro 4가 답변 초안 작성
  4. 담당자 검토 후 회신

빛을 받는 방법

같은 기능, 세 가지 연결

근거 행성은 같은 기능을 세 방식으로 실행합니다. 공공기관은 온프렘으로 외부 전송 없이 씁니다.
